# Vijay ❤️ Hemalatha Wedding Invitation

Premium responsive wedding invitation landing page with a champagne/gold envelope cover, subtle ambient motion, interactive glowing seal, and smooth open transition into the invitation details.

## Files
- `index.html` — landing page and invitation content
- `css/style.css` — responsive design and animations
- `js/countdown.js` — countdown and envelope interaction
- `assets/wedding-envelope.png` — invitation artwork

The animation automatically respects `prefers-reduced-motion` for accessibility.
