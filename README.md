## RSVP — make it live
1. Create a Google Sheet.
2. Create a tab named `RSVP`.
3. Open Extensions → Apps Script.
4. Paste `rsvp-google-apps-script.gs`.
5. Deploy it as a Web App with access set to Anyone.
6. Copy the `/exec` URL into `js/config.js`:
   rsvpWebAppUrl: "YOUR_EXEC_URL"
7. Commit the changed config file.
8. Added
